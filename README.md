# CS134 Project - Hood
Hood is a 2.5D platform game where you fight fungus creatures and maneuver through various levels.

# Setup
- 3D built in Rendering Pipline (Unity 2022.3.62f3)
- Download and Install Unity Input System from Package Manager Unity Registry
- Download and Install Cinemachine from Package Manager Unity Registry
- Download and Install Shader Graph from Package Manager Unity Registry
- Create Layer Mask: Ground, Platform, OneWayNoDrop
